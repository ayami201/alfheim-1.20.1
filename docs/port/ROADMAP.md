# Контрольные точки порта

Каждая КТ заканчивается PR в `port/1.20.1` с отчётом и чек-листом для
владельца. Следующая КТ начинается, когда PR влит. Порядок задан зависимостями:
сначала то, на чём стоит остальное.

Менять порядок или делить КТ на части можно. Решение записывается в журнал
`TASKS.md` с причиной. Внутри КТ работа дробится на пункты в `TASKS.md`. Одна
КТ может занять несколько сессий.

Пути ниже — внутри `legacy/src/main/java/alfheim/`. «Строк» — объём кода автора
в КТ, для планирования. Отнесение каждого файла к КТ — в `INVENTORY.md` (её
составляет КТ-0). Если файл не подходит к КТ, куда его отнесли, его можно
перенести в другую КТ с пометкой в описи.

Кто проверяет: **CI** — сборка и GameTest-ы в GitHub Actions; **👁 владелец** — в игре, по чек-листу из PR.

## КТ-1. Фундамент

**Цель.** Всё, на что опираются блоки и предметы: прослойки, регистрация, конфиг, сеть, переводы.

**Объём.**
- Прослойка `alfheim.port.legacy` (SPEC, Р-4) — минимум, нужный КТ-2. Дальше растёт по мере надобности.
- Части ASJCore, которые нужны КТ-2 (`alexsocol.asjlib`: `math`, `ItemNBTHelper`, базовые расширения).
- Регистрация: DeferredRegister, правило имён, файл `legacy_ids.json` (SPEC, Р-5).
- Конфиг: `core/handler/AlfheimConfigHandler.kt`, `AlfheimPreConfigHandler.kt` → ForgeConfigSpec (Р-12).
- Сеть: канал и регистрация пакетов. Сами пакеты — вместе с механиками.
- Вкладка творческого режима (`core/util/AlfheimTab.kt`), `core/util`, `core/helper`, нужное из `api/`.
- Переводы: `.lang` → `.json` для en_us, ru_ru, zh_cn скриптом. Скрипт коммитится, ключи переименовываются по `legacy_ids.json`.
- Опыт: запуск клиента без экрана в облаке (Xvfb + программный OpenGL) ради
  скриншотов блоков и существ. Не больше одной сессии. Если не завелось —
  записать в «Найдено», почему, и не возвращаться.

**Готово, когда.**
- Файлы конфига создаются со всеми опциями автора, кроме списка «потеряли смысл» в MAPPING.md.
- Число ключей в каждом `.json` перевода = ключи оригинала минус удалённые (сверка скриптом).
- GameTest регистрации проходит.

**Проверяет:** CI. **Строк:** около 4 тыс. + части ASJCore.
