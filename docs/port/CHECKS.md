# Проверки, которые агент не выполнил

Сюда записывается всё, что агент не смог проверить запуском: нужен клиент с видеокартой и
звуком, сеть, которой нет в облаке, долгая игра или сборка владельца. Источник — раздел
«Проверка» PR (CLAUDE.md, «Проверка»).

**Важность.**
- `в игре` — проверяет владелец в своей сборке; пункт попадает в чек-лист «Проверка в игре»
  PR «КТ-n готова» своей КТ.
- `важная` — без неё нельзя идти дальше (например, мод может не запуститься у игроков). Агент
  останавливается, пишет инструкцию для агента на ПК владельца — файл `checks/<номер>.md` в этой
  папке — и отправляет её владельцу; владелец запускает агента и присылает отчёт.
- `облако, позже` — агент может проверить сам, но позже (нужна КТ, которой ещё нет).

**Как вести.** Номер `C-NNN` не переиспользуется. Когда проверка выполнена — в «Статус» дата,
кто проверил и итог; если нашлась ошибка — строка в «Найдено» `TASKS.md`.
